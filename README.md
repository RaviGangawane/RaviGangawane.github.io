# Ravi Gangawane Portfolio - Image to HTML/CSS

This package contains a deploy-ready HTML/CSS conversion of the uploaded futuristic portfolio image.

## Included files

- index.html
- styles.css
- assets/logo/logo.png

## Deploy

Upload all files to your hosting provider or GitHub Pages repository.

For GitHub Pages:
1. Extract the ZIP.
2. Copy all files into your `ravigangawane.github.io` repository.
3. Commit and push.
4. Visit your GitHub Pages URL.

## Edit

- Change text/content in `index.html`
- Change colors/layout in `styles.css`
